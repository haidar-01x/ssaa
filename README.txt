Birthday page for Mr. Abdul Majeed Ibikunle (from his wife)

DEPLOY ON VERCEL
1. Unzip this file. You should see index.html, vercel.json and the audio folder.
2. Go to vercel.com > Add New > Project.
3. Upload / import THIS folder (the one that contains index.html directly).
4. Framework Preset: "Other". Leave Build Command and Output Directory empty.
5. Deploy.

Or with the Vercel CLI, from inside this folder:  npx vercel --prod

EASIEST ALTERNATIVE: app.netlify.com/drop  -> drag this folder onto the page.
